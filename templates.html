Round 1 approach briefs

Each brief attacks a specific competitor gap identified in the competitor queue. The brief drives the template — don’t ship a template without matching it to its brief’s visual hierarchy and headline options.

A — Pro Toolkit Stack

Gap attacked: pro-grade production-tool credibility

Core angle: Show the actual tools — Kontakt, Massive X, Guitar Rig, Ozone, Neutron — that pros use on records. Credibility via specificity.

Headline options:

  • “The tools on the records you love. From $15/mo.”
  • “Real plugins. The ones on actual records.”
  • “Kontakt, Massive X, Ozone — $15/mo. Yes, really.”

Visual: 4–6 plugin UI windows in a grid; plugin name labels; CTA with price pill.

B — Price Anchor / Updates Included

Gap attacked: outright-vs-subscription price comparison (nobody running this)

Core angle: Compare outright Komplete (~$1,599) vs $15–50/mo — lead with “all future updates included” to kill the perpetual-vs-sub objection.

Headline options:

  • “$1,599 outright. Or $15/mo — with every update included.”
  • “You don’t own your plugins forever. You own them this year.”
  • “Stop buying updates. Start getting them.”

Visual: side-by-side comparison table, total row, updates-included row with ✓/✗, dual price pill.

C — Named Producer Credibility

Gap attacked: pro credits vs generic creator testimonials

Core angle: A testimonial from a named, credited producer or ME — quote + credits + the plugins they rely on as pills.

Headline options (the quote is the headline):

  • “I use Kontakt on every session. Massive X on half of them. 360 pays for itself the first week.”
  • “Ozone and Neutron are on every master I turn in.”
  • “The Guitar Rig amp sim I used on [Track] is in 360.”

Visual: producer photo/studio shot + quote, attribution, plugin pills, 5-star rating, CTA.

How to populate a template

  1. Open the matching HTML template in NI_360_Ad_Framework/templates/.
  2. Edit the CONFIG block at the top of the file — headline, subheadline, CTA copy, image paths.
  3. Drop the images referenced in the config into templates/images/. Recommended sizes are listed in each template’s comments.
  4. Open the HTML file in a browser to preview all three aspect ratios (4:5, 1:1, 9:16). The template renders all three side by side.
  5. Cross-check the asset tracker for what’s still missing; mark Done as you go.
  6. Export the rendered ad (screenshot at marked dimensions, or use the browser’s print-to-PDF with a fixed viewport) and hand off to Smartly.
File naming for Smartly hand-off: NI_NI360_R[N]_[A|B|C]_[format].[ext], e.g. NI_NI360_R1_A_4x5.jpg. Leo owns enforcement.

Legal flags (by approach)

  • A — Pro Toolkit: plugin UI screenshots must be current-version; any artist endorsement needs consent.
  • B — Price Anchor: individual plugin prices must be verified at go-live. “All future updates included” wording needs legal approval. Comparison total must round cleanly or it reads as dodgy.
  • C — Producer Quote: quote must be attributed, verified, consented in writing. Credits must be accurate. Star rating must be sourced from a verifiable platform (Trustpilot, G2, Google Reviews) — not fabricated. UGC consent documentation must be on file before ship.
