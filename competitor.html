Territory NOT claimed (gaps NI 360 can own)

1. Pro-grade production-tool credibility

None of the three leans on “these are the tools used on actual pro records.” Splice is sample-first, LANDR is AI-first, Output is aspirational-creator-first.

NI’s claim: legitimate via Kontakt, Massive X, Guitar Rig, iZotope Ozone/Neutron, Brainworx — the plugins that actually appear on chart records. This is the clearest gap.

Round 1 approach: A — Pro Toolkit Stack Live

2. Price anchor vs outright ownership

Nobody runs “this would cost you $X if you bought it — get it for $Y/mo, updates included.” Splice lacks catalog depth; LANDR’s pricing story is annual-vs-monthly; Output avoids pricing in copy.

NI’s claim: the sub’s strongest rational argument — Komplete-outright-vs-NI-360, and nobody’s making it.

Round 1 approach: B — Price Anchor / Updates Included Live

3. Named producer credibility / pro credits

Competitors use generic creator testimonials or no testimonials. NI’s artist roster (the producers and engineers who use Kontakt, Massive X, iZotope) is genuinely at a different tier.

NI’s claim: naming them wins the trust argument in a way a creator quote can’t.

Round 1 approach: C — Named Producer Credibility Live

Gaps claimed but weakly

“All updates included” — LANDR mentions it in copy but doesn’t lead with it. NI 360 can make it the headline.

Feature breadth — Splice and LANDR both claim it generically. NI 360 can claim it specifically (Kontakt + Massive X + Guitar Rig + Ozone = breadth AND depth).

These feed the bench angle and future rounds if a Round 1 approach is retired.

Scan process

Who runs it: Parm (framework lead). How it works today: manual — pulling the Meta Ad Library for each competitor in the scan set. The Start scan → button at the top opens the Meta Ad Library in new tabs for every competitor in the scan set plus anyone you’ve ticked on this page — that cuts the 10–15 min of tab-opening admin. The observation work (logging angles, visuals, copy moves) still happens by hand.

  1. Click Start scan → — a tab opens per competitor, filtered to active ads.
  2. For each competitor, capture 3–5 top-running creatives — the ones running for weeks signal spend commitment.
  3. For each creative, log: format, visual pattern, headline, CTA, price display, UI-vs-lifestyle imagery.
  4. Roll findings into the “Territory claimed” section (update competitor.html in the repo).
  5. The “Territory NOT claimed” section feeds the next approach briefs — specifically the angles that fill slots opened by graduates or retirees.
Before every round. The scan happens at round kickoff, not just when a loser is retired. Competitor positions shift faster than our rounds — if we only scan when we need a new angle, we’ll miss when a gap closes.
Automating the scan further. The Start-scan button opens tabs; the logging is still manual. If we want the full scan summarised by an agent (pulling top creatives, transcribing copy, flagging visual patterns), that’s a scheduled-task layer on top — ping Jordan when you’re ready to wire it up.
