# Image drop folder

Drop all ad imagery here. The HTML templates reference these paths.

## Approach A — Pro Toolkit Stack

- `kontakt.png` — Kontakt 8 library UI screenshot
- `massive_x.png` — Massive X patch browser or oscillator view
- `guitar_rig.png` — Guitar Rig signal chain
- `ozone.png` — Ozone 11 module chain
- `neutron.png` — Neutron 5 mixing view
- `battery.png` — Battery 4 pad grid

All PNG, minimum 600×600 (will scale down). Transparent or dark backgrounds preferred.

## Approach B — Price Anchor

No images beyond the NI 360 logomark (already rendered as HTML text).

## Approach C — Pro Quote

- `producer_portrait.jpg` — the named producer's portrait or studio shot. Landscape or portrait both work. Minimum 1080px on the long edge. Dark background or dramatic lighting fits the template best.

## Shared

- `ni_360_logo_red.svg` (optional — currently rendered as HTML text; swap in when brand team provides official mark)

---

Filename convention: lowercase, underscores, no spaces. Update the `CONFIG` block in the corresponding HTML file if you rename anything.
